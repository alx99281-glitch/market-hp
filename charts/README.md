# マーケットチャート（タブ1）

日経平均・S&P500の10年ローソク足チャート。レンジスライダー・期間ボタン・
カスタム日付範囲、ローソク足ホバー時の中央銀行イベント／主要市場材料表示。

## 使い方

```bash
python -m pip install yfinance
cd src
python fetch_chart_data.py          # 10年分OHLCを取得（毎回全期間再取得でよい軽量データ）
python central_bank_events.py       # FRB/日銀イベントJSON生成
python general_market_events.py     # その他の主要市場材料JSON生成
python build_page.py                # -> output/index.html
```

`output/index.html` をブラウザで開く、またはHTTPサーバーで配信すれば動作する
（Plotly.jsをcdnjsから読み込むため、閲覧時にインターネット接続が必要）。

## 実装メモ・制約

- チャート描画は Plotly.js（cdnjs, `plotly.js@4.0.0`）。ローソク足 +
  `rangeslider`（下部のドラッグ式期間選択バー）+ `rangeselector`（6ヶ月/1年/
  3年/5年/全期間ボタン）を標準機能で実装。カスタム日付範囲は
  `<input type="date">` 2つ + `Plotly.relayout` で実現。
- ホバー時のニュース表示は Plotly標準のツールチップ内ではなく、
  `plotly_hover` イベントを拾って専用のニュースパネル（チャート下部）に
  描画する方式（OHLC情報とニュースの両方を同時に見せるため）。
- 中央銀行イベントの日には縦の点線（FRBは青、日銀は赤）を常時表示し、
  ホバーしなくても「その日に何かあった」ことが一目でわかるようにしている。
- **中央銀行イベントのデータ精度**: FOMCは2016年以降ほぼ全会合を収録
  （利上げ/利下げ幅・据え置きを記載）。2025年分はWeb検索で実際の結果を確認
  済み。2026年分は開催日程のみ判明しており結果は「要検証」と明記している。
  日銀は主要な政策変更（マイナス金利導入・YCC導入/修正/撤廃・利上げ）を
  中心に収録しており、据え置きのみの通常会合は全件を網羅していない
  （無料ソースで全会合の正確な日程・結果を検証する時間的制約のため）。
  本番運用では日銀公式サイトの会合日程ページから機械的にスクレイピングし、
  全会合を網羅すべき。
- **中央銀行イベント以外のニュース**: 代表的な大型イベント11件のみを手動で
  シードしたデモ状態（COVID急落、SVB破綻、2024年8月の円キャリー巻き戻し
  など）。仕様書が求める「日米の主要ニュース媒体を毎日チェックして全営業日
  分ストックする」には至っていない。daily-review側で実装した
  `news_lookup_batch.py`（Anthropic API + web_search）と同じ仕組みを
  日次バッチとして走らせ、中央銀行イベントと同じJSON形式
  （`{"date":..., "region":..., "detail":...}`）で `general_market_events.json`
  に追記していけば、このページはコード変更なしでそのまま拡充された内容を
  表示できる設計にしてある。
- ホバーの当たり判定はPlotly側の仕様上、ローソク足のごく近傍にマウスが
  来る必要がある（自動テストでは実際に座標を合わせて動作確認済み）。
