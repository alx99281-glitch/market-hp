# マーケット分析ダッシュボード

3タブ構成のHP。`index.html` がタブ切り替え式のトップページ（iframeで各サブサイトを表示）。

## 構成

```
market-hp/
  index.html          トップページ（3タブ切り替え、iframe方式）
  charts/             タブ1: マーケットチャート（日経平均・S&P500、10年ローソク足）
  daily-review/        タブ2: 日次市場サマリー（米国・日本、SPEC_1.md実装）
  boards/               タブ3: 中央銀行審議委員まとめ（タカ派/ハト派スコア）
```

各サブディレクトリの詳細は、それぞれの README.md を参照。

## ローカルでの確認方法

`index.html` はiframeで各サブサイトを読み込むため、`file://` で直接開くとブラウザの
セキュリティ制限で正しく動作しない場合がある。ローカルHTTPサーバー経由で開くこと。

```bash
cd market-hp
python -m http.server 8000
# ブラウザで http://localhost:8000/index.html を開く
```

## 公開について

現時点ではローカル確認のみ（自分専用）。将来的に一般公開する場合は、この
`market-hp/` ディレクトリ全体を静的ホスティング（GitHub Pages, Netlify, S3等）に
アップロードすればそのまま動作する（すべて静的ファイルのみで構成）。

日次データ（daily-review）を自動更新し続けるには、`daily-review/README.md` に
記載の日次バッチ（データ取得→ニュース照合→レポート生成）をcron等でスケジュール
実行し、生成物をホスティング先に同期する仕組みが別途必要（フェーズ8、未実装）。
