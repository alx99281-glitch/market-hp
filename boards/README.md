# 中央銀行審議委員まとめ（タブ3）

FRB(FOMC投票メンバー12名)・日本銀行政策委員会(9名)のプロフィールと
タカ派/ハト派スコアをまとめたページ。

## 使い方

```bash
cd src
python build_page.py   # -> output/index.html
```

## 実装メモ・制約

- メンバー構成は2026年9月時点で確認済み（Web検索で裏付け）。
  訓練データのカットオフ(2026年1月)以降にケビン・ウォーシュ氏のFRB議長就任
  （2026年5月、パウエル氏の後任）、日銀審議委員2名の交代
  （浅田統一郎氏 2026年4月〜、佐藤綾野氏 2026年6月〜）などの人事異動が
  あったため、それらを反映済み。ただし人事は頻繁に動くため、公開前に
  各公式サイト（federalreserve.gov / boj.or.jp）での再確認を推奨する。
- **タカ派/ハト派スコア(-5〜+5)は編集部による定性評価**であり、発言全文を
  機械的にNLP解析して算出した客観指標ではない。公開されている経歴・過去の
  代表的な発言・報道内容（例: 日銀新任2名は複数メディアで「リフレ派」と
  報じられている）を基にした主観的な位置づけである旨を、ページ本文にも
  明記している。本格的な運用では、過去の議事録・記者会見録・講演テキストを
  収集し、Claude API等で定量的なスコアリングを行う仕組みへの拡張が必要
  （tab2の `news_lookup_batch.py` と同様、テキスト収集にはAPIキーが必要）。
- **写真**: 著作権上の懸念を避けるため、実際の顔写真は掲載せず、
  氏名イニシャルのアバターで代替している。各カードの「公式略歴 →」リンクは
  Federal Reserve Board / Bank of Japan 公式サイトの本人ページに直接リンク
  しており、そこで本物の写真を確認できる。ユーザー自身が権利関係を確認の上、
  `build_page.py` の `member_card()` を画像タグに差し替えることも可能。
- データは `data/members.json` に集約。人事異動があれば同ファイルを編集し
  `build_page.py` を再実行するだけで反映される。
